Project statement

AI/ML-Based Integrated heavy rainfall Early Warning and Inundation Prediction System using Satellite, Radar, observational Weather and numerical weather prediction model data.

  • Live observations + NWP-compatible forecast
  • NASA GPM IMERG satellite precipitation
  • RainViewer radar visualization/metadata
  • 17-feature prototype ML inference engine
